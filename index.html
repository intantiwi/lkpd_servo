Praktik Motor Servo SG90

Rangkai servo, kendalikan sudutnya, amati perubahan gerakan, lalu selesaikan tantangan modifikasi kode.

👥 Kelompok 3 orang💻 Arduino Uno + SG90🎯 Demonstrasi & file .ino

Target hari ini: servo dapat bergerak sesuai sudut yang ditentukan, gerakannya dapat dibuat bertahap, dan setiap kelompok mampu memodifikasi kode dasar secara mandiri.

Bagian A

Persiapan rangkaian

Pastikan koneksi benar sebelum menyambungkan USB Arduino.

⚠ Aturan utama: cabut kabel USB sebelum memasang, melepas, atau mengubah sambungan. Jangan memaksa poros/horn servo, dan hentikan jika servo terasa tertahan atau terlalu panas.
Kabel SG90Hubungkan ke Arduino Uno
Cokelat · GNDGND
Merah · VCC5V
Oranye · sinyalD9

Gambar menunjukkan hubungan kabel, bukan lokasi fisik pin pada papan. Periksa tulisan pin di Arduino. Warna kabel bisa berbeda pada servo tipe lain.

Horn servo masih terpisah? Lihat cara memasangnya
  1. Jika ingin posisi horn rapi, jalankan kode pemusatan 90° berikut saat horn belum terpasang.
  2. Setelah poros berhenti, cabut USB.
  3. Pasang horn satu lengan ke arah yang mudah diamati, lalu kencangkan sekrup kecil secukupnya (jangan terlalu keras).
  4. Pastikan horn tidak membentur meja atau benda lain sebelum menjalankan kode berikutnya.

Bagian B

Praktik 1: mengubah posisi servo

  1. Salin Kode A ke Arduino IDE, pilih board dan port yang sesuai, lalu upload.
  2. Amati servo bergerak antara dua posisi.
KODE A · POSISI SERVO
#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  myServo.write(45);
  delay(1500);

  myServo.write(135);
  delay(1500);
}
🔎 Coba dua perubahan berikut:
  1. Ubah 45 dan 135 menjadi 30 dan 120, lalu upload ulang.
  2. Ubah kedua delay(1500) menjadi delay(3000), lalu upload ulang.

Amati: apa yang berubah pada posisi servo? Apa yang berubah ketika nilai delay() diperbesar? Diskusikan bersama kelompok.

Bagian C

Praktik 2: gerakan perlahan dengan for

  1. Salin dan upload Kode B. Perhatikan bedanya dengan Kode A.
  2. Ubah hanya delay() di dalam kedua perulangan for, lalu bandingkan gerakannya.
KODE B · GERAKAN BERTAHAP
#include <Servo.h>

Servo myServo;

void setup() {
  myServo.attach(9);
}

void loop() {
  for (int sudut = 20; sudut <= 160; sudut++) {
    myServo.write(sudut);
    delay(20);
  }

  delay(1000);

  for (int sudut = 160; sudut >= 20; sudut--) {
    myServo.write(sudut);
    delay(20);
  }

  delay(1000);
}

Bandingkan tiga nilai delay per langkah

10 msUji dan amati
20 msNilai awal kode
50 msUji dan amati

Diskusikan: makin besar nilai jeda per langkah, gerakan terlihat makin cepat atau lambat? Ingat: servo tetap mempunyai batas kecepatan fisik.

Bagian D

Tantangan modifikasi

Gunakan Kode B sebagai dasar.

🎯 Misi kelompok
  1. Servo bergerak bertahap dari 30° ke 150°.
  2. Program menunggu selama 2 detik.
  3. Servo kembali menuju 30° dengan gerakan lebih cepat.
  4. Gerakan tersebut berulang terus-menerus.
✅ Verifikasi guru: tunjukkan gerakan servo kepada guru. Salah satu anggota kelompok menjelaskan bagian kode yang diubah. Simpan kode akhir berformat .ino.
